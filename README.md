# Instagram Feed

Webサイトに埋め込める「Instagram投稿の横スクロール表示」と、表示する投稿を選ぶ管理画面です。
GitHub Pages だけで動きます（サーバー不要・無料）。

- **表示**：選んだ投稿の写真だけが横スクロールで並び、写真をクリックすると本文付きの詳細が開きます。Instagram 公式の埋め込みを使うので画像をコピーせず、投稿者が削除・埋め込み無効にすると自動的に表示されなくなります。
- **選ぶ**：Chrome 拡張を入れると、Instagram の画面の写真に「＋」ボタンが付き、押すだけで選べます（選んだ写真は緑の枠と ✓）。保存も自動で、1〜2分で埋め込みに反映されます。API・審査は不要です。
- **管理画面**：並べ替え、選択の確認・解除、アカウントの登録など。
- **自動収集（後から有効化）**：指定ユーザー／ハッシュタグの新しい投稿を毎日「未確認の候補」に追加します。

## ファイル構成

| パス | 内容 |
|---|---|
| `embed.html` | 埋め込み用の横スクロール表示 |
| `admin/index.html` | 管理画面 |
| `admin/pick.html` | ブックマークで選ぶときの小窓（拡張を使わない場合） |
| `extension/` | Chrome 拡張「Instagram Feed ピッカー」 |
| `data/posts.json` | 投稿リスト（`approved: true` のものだけ表示） |
| `data/sources.json` | 自動収集の対象（アカウント・ハッシュタグ・設定）。管理画面で編集 |
| `data/collect_status.json` | 前回の自動収集の結果（自動生成） |
| `scripts/collect.mjs` | 自動収集スクリプト |
| `.github/workflows/collect.yml` | 自動収集の定期実行（毎日 6:17 JST） |

## 1. GitHub Pages を有効にする

1. リポジトリの **Settings → Pages** を開く
2. Source: **Deploy from a branch**、Branch: **main** / **/(root)** を選んで Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

※ 無料プランの GitHub Pages は公開リポジトリが必要です。データ（どの投稿を表示するか）は公開されますが、トークン等の秘密情報はリポジトリに置きません。

## 2. 管理画面用のトークンを作る

1. GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token
2. Repository access: **Only select repositories** → このリポジトリ
3. Permissions → Repository permissions → **Contents: Read and write**（管理画面から「今すぐ収集を実行」したい場合は **Actions: Read and write** も）
4. 発行された `github_pat_...` を、管理画面の「接続設定」に入力して「接続して読み込み」

トークンはそのブラウザ内にのみ保存されます。複数人で管理する場合は、各自がこのリポジトリへの書き込み権限を持ち、自分のトークンを使ってください。

## 3. Chrome 拡張で投稿を選ぶ（おすすめ）

### 入れ方（最初に1回）
1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオン
3. **パッケージ化されていない拡張機能を読み込む** → このリポジトリの `extension` フォルダを選ぶ
4. 拡張の **詳細 → 拡張機能のオプション**（またはツールバーの拡張アイコン → 設定）で、GitHub のユーザー名・リポジトリ名・トークン（管理画面と同じもの）を入れて「保存して接続を確認」
5. 開いている Instagram のタブを再読み込み

ツールバーのパズルのアイコンから、この拡張をピン留めしておくと便利です。

他の人にも選んでもらう場合は、その人をこのリポジトリの共同編集者（Settings → Collaborators）に追加し、その人が自分のトークンを作って拡張に入れてください（トークンの共有はしない）。

### 使い方
- **プロフィールや検索の一覧**：各写真の左上の **＋** を押すと選択、もう一度押すと解除。選択中の写真は **緑の枠と ✓** になります（写真を開かずに選べます）
- **選択モード**（一覧で左下の「選択モード」ボタン）：オンの間は **写真をクリックするだけで選択／解除** できます（投稿は開きません）。下へスクロールすれば古い投稿も選べます。本文を確認したいときは「終了」でオフにすると、クリックで投稿が開くようになります。オン・オフは次回も引き継がれます
- **投稿を開いているとき**：右下の **「＋ この投稿を選ぶ」**（選択中は「✓ 選択中」）
- **ホームのフィード**：各投稿の、いいね・コメント・シェアの列の右側（保存アイコンの左）の **＋**。広告の投稿には付きません
- 押すと自動で保存され、画面下に「✓ 選びました」と出ます。1〜2分で埋め込みに反映されます
- 拡張アイコンを押すと、選択中の件数と「表示を確認」「管理画面」へのリンクが出ます

注意：Instagram の画面の作りが変わると、ボタンが出なくなることがあります（その場合は `extension/content.js` の修正が必要です）。拡張を更新したときは `chrome://extensions` で再読み込みボタンを押してください。

## 4. 管理画面の使い方

`https://<ユーザー名>.github.io/<リポジトリ名>/admin/`

- **アカウント**：よく見るアカウントを登録しておくと、「投稿を選ぶ」欄に最新投稿が並び、クリックで Instagram が開きます。「埋め込みの先頭にアカウントの枠も表示する」をオンにすると、アカウントの枠（最新6件）も埋め込みに出ます（通常はオフ）
- **ブックマークで選ぶ**（拡張を使わない場合）：「投稿を選ぶ」欄の「拡張を使わない方法」から「📌 投稿を選ぶ」をブックマークバーへドラッグ → Instagram で投稿を開いて押す
- 拡張で選んだ分は、この画面に戻ってくると自動で読み直されます（未保存の変更が無いとき）
- **投稿一覧**：本文付きの大きなカードで表示。「＋ 選ぶ／✓ 選択中」ボタンで切り替え（選択中は緑の枠と「✓ 選択中」の印）。「大きく見る」で1件ずつ拡大表示（← → キーで前後、Esc で閉じる）。一覧で切り替えた場合は「保存」を押す
- **投稿を追加**：Instagram の投稿URL（`/p/…`、`/reel/…`、`/ユーザー名/p/…` など）を1行1件で貼り付け
- **← →**：「選択中」タブで表示順を入れ替え
- **見送り**：候補を表示せずに確認済みにする（「すべて」タブには残る）
- **除外**：一覧から削除。自動収集でも再追加されなくなります
- **自動収集の対象**：アカウント（ユーザー名またはプロフィールURL）とハッシュタグを追加・削除。ハッシュタグ検索の有効／無効、1対象あたりの取得件数もここで設定します。各対象の前回の収集結果（取得件数・エラー）も表示されます
- **今すぐ収集を実行**：毎日の定期実行を待たずに収集します（保存してから押す）
- 最後に **保存（GitHubに反映）** を押す

自動収集と同時に保存すると競合することがあります。その場合は「接続して読み込み」で読み直してから操作してください。

## 5. サイトに埋め込む

iframe で以下のURLを読み込みます（Wix なら **追加 → 埋め込み → HTMLの埋め込み（iframe）** →「ウェブサイトのアドレス」）：

```
https://<ユーザー名>.github.io/<リポジトリ名>/embed.html?auto=5
```

写真の高さが 240px（既定）なら、要素の高さは **約 270px** で写真の列がちょうど収まります。
写真をクリックしたときの詳細はこの枠の中に開くので、詳細を大きく見せたい場合は枠を高く（600〜700px 程度）してください。枠を低いままにしたい場合は `detail=link`（クリックで Instagram の投稿ページを新しいタブで開く）を付けます。

### 表示オプション（URLパラメータ）

| パラメータ | 例 | 内容 |
|---|---|---|
| `size` | `size=200` | 写真の高さ（px、既定 240）。幅は写真・動画の縦横比に合わせて自動 |
| `detail` | `detail=link` | クリックで詳細を開かず、Instagram の投稿ページを新しいタブで開く |
| `who` | `who=0` | 写真の上の「@投稿者名」を出さない |
| `auto` | `auto=5` | 5秒ごとに自動スクロール（マウスを乗せると停止） |
| `max` | `max=20` | 最大表示件数（既定 50） |
| `bg` | `bg=ffffff` | 背景色 |
| `user` | `user=natgeo,nasa` | アカウントの枠を直接指定して表示（管理画面の設定より優先） |
| `posts` | `posts=0` | 個別の投稿を出さず、アカウントの枠だけ表示 |
| `w` | `w=300` | アカウントの枠の幅（px、既定 326） |

写真のサムネイルは、公式埋め込みのヘッダーなどを隠して写真の部分だけを縮小しています。高さはそろえ、幅は投稿の縦横比どおり（縦長は Instagram の上限の 4:5）。動画（リール）は左右の黒帯を除いた映像部分を表示します。投稿者名などは、クリックした詳細の方に表示されます。

## 6. 自動収集を有効にする（任意・API が必要）

前提：APIを使う自分の Instagram アカウントが **プロアカウント（ビジネス/クリエイター）** で、**Facebook ページと連携** していること。

1. [Meta for Developers](https://developers.facebook.com/) でアプリを作成し、「Instagram API with Facebook Login」を追加
2. 権限 `instagram_basic`、`pages_show_list`、`pages_read_engagement`（必要に応じて `business_management`）で長期アクセストークンを取得
3. そのアカウントの **IG User ID** を取得
4. このリポジトリの **Settings → Secrets and variables → Actions** に登録
   - Secrets：`IG_USER_ID`、`IG_ACCESS_TOKEN`
   - Variables（任意）：`GRAPH_VERSION`（例 `v23.0`）
5. 管理画面の「自動収集の対象」にアカウント／ハッシュタグを追加して保存
6. 管理画面の「今すぐ収集を実行」（または Actions タブ → *Collect Instagram candidates* → **Run workflow**）で試運転

### 制約

- **審査なしでできること**：アカウントの表示（プロフィール埋め込み）と、投稿URLの手動追加は API も審査も不要です。ユーザー指定の自動収集（Business Discovery）も、自分が管理者の Meta アプリ（開発モード）で自分のトークンを使う限り、通常は App Review なしで動きます。
- **ハッシュタグは審査が必要**：ハッシュタグで投稿を集める公式の方法は Hashtag Search API だけで、Meta の審査が必要です。審査なしでハッシュタグの投稿を出したい場合は、見つけた投稿のURLを手動で追加してください。

- **ユーザー指定**（Business Discovery）：取得できるのは **ビジネス／クリエイターアカウントの投稿のみ**。個人アカウントの投稿は、従来どおり URL を貼って追加してください。
- **ハッシュタグ指定**（Hashtag Search）：Meta の **App Review（Instagram Public Content Access）** の承認が必要。承認後に管理画面で「ハッシュタグ検索を有効にする」にチェックして保存すると有効になります。検索できるのは **7日間で30種類のハッシュタグまで**。
- 長期アクセストークンには有効期限があります。期限が切れたら更新して Secrets を差し替えてください。
- 自動収集で集めた投稿も、表示はすべて公式埋め込みです（画像をリポジトリに保存しません）。

## 運用メモ

- 他の方の投稿をサイトに常設で掲載するため、掲載する相手には一言断っておくと安心です。
- 投稿者が埋め込みを無効にしている投稿は、カードが空になったり「表示できません」と出たりします。その場合は管理画面で「表示する」を外してください。
