接続設定（GitHub）

「今すぐ収集を実行」も使う場合は、トークンに Actions: Read and write も付けてください。トークンはこのブラウザ内（localStorage）にだけ保存されます。共用PCでは使い終わったら「設定を消去」してください。トークンなしでも閲覧はできます（保存は不可）。

アカウントAPI不要

編集するには、上の「接続設定」でトークンを入力して接続してください。

登録したアカウントの最新投稿が、下の「投稿を選んで追加」に並びます。公開アカウントならビジネス／個人を問わず使えます（非公開アカウントは表示されません）。

    投稿を選ぶAPI不要

    おすすめ：Chrome 拡張「Instagram Feed ピッカー」

    Instagram の画面の写真に「＋」ボタンが付き、押すだけで選べます（選んだ写真は緑の枠と ✓）。投稿を開いているときは右下の「＋ この投稿を選ぶ」。保存も自動です。入れ方は README の「Chrome 拡張」を参照してください。

    下のアカウント一覧のサムネイルをクリックすると、Instagram がその投稿を開きます。

    拡張を使わない方法（ブックマークで選ぶ）

    このボタンをブックマークバーへドラッグ → 📌 投稿を選ぶ　Instagram で投稿を開いた状態で押すと、小窓で選択・保存します。

    URLを貼り付けて追加する

    投稿一覧

    選択中の投稿だけが、この並び順で埋め込みに表示されます（← → で入れ替え）。「大きく見る」で本文まで確認できます。「除外」した投稿は自動収集でも再度追加されません。

    自動収集の対象Instagram API が必要

    編集するには、上の「接続設定」でトークンを入力して接続してください。

    ここに登録したアカウント・ハッシュタグの新しい投稿を、毎日 6:17（日本時間）に「未確認の候補」へ追加します。変更したら「保存（GitHubに反映）」を押してください。収集には Instagram API の設定（README の手順5）が必要です。

    アカウント

      取得できるのはビジネス／クリエイターアカウントの投稿のみです。個人アカウントは上の「投稿を追加」でURLを貼ってください。

      ハッシュタグ

        Instagram の制限で、検索できるのは7日間で30種類までです。
